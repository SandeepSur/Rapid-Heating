# Rapid Heating & Plumbing Ltd 🔧🔥

Official modern, high-converting landing page for **Rapid Heating & Plumbing**, certified Gas Safe registered engineers serving Denton and Greater Manchester since 2007.

## 🚀 Key Features

- **Hero Section:**
  - Recommended Manchester heating & plumbing headline and high-converting copy.
  - Dual action CTAs: *Get a Free Quote* and *Click-to-Call +44 7535 352870*.
  - Verified *5.0 on Google* rating badge linked to Google Maps.
  - Interactive technician cutout and floating appointment card.
- **Animated Statistics Bar:**
  - Dynamic JavaScript counting counters (30+ Years of Service, 25k+ Projects Completed, 10 Service Awards, 191 Expert Engineers).
- **Why Homeowners Trust Us:**
  - 4 core value proposition cards highlighting Gas Safe certification, zero-cost assessments, longevity, and warranties.
- **Our Services Grid:**
  - 3×2 interactive service cards (*General Plumbing, Boiler Installations & Repairs, Landlord CP12, Commercial Catering, EPC Certificates, Gas Cookers*).
  - Dual CTAs per card (*Book Service* + *Know More* with interactive details modal).
- **Domestic Heating Specialists Commitment:**
  - Clean, domestic setting photography with 4-item checklist (*On-Time Arrivals, Clean & Tidy Work, No Surprise Charges, Aftercare Support*).
- **Verified Google Maps Reviews:**
  - Connected directly to Google Maps profile (`cid=11139797075366942964`).
  - Google rating score summary pill and customer review cards with verified badges.
- **Got Questions? (FAQs Accordion):**
  - Smooth interactive accordion answering customer inquiries about quotes, Gas Safe IDs, emergency response times, and CP12 certificates.
- **Book Your Engineer Section:**
  - Comprehensive quotation form with date picker, address, service selector, and issue description.
  - 4 direct contact cards: Location (*47 Hulme Rd, Denton, Manchester M34 2WX*), Direct Phone (*+44 7535 352870*), Email, and Opening Hours (*Mon–Sat, until 6pm*).
- **Brand Identity & Theming:**
  - Authentic Rapid Heating dual fire-and-water logo in header and footer.
  - Brand flame orange (`#e85a1d`) and water/gas blue (`#0084d6`) color palette.
  - Fully responsive across desktop, tablet, and mobile.

## 🛠️ Tech Stack

- **HTML5:** Semantic, accessible markup.
- **CSS3:** Custom responsive layout, CSS variables, smooth cubic-bezier transitions, modern flexbox & CSS grid.
- **JavaScript (Vanilla ES6+):** Intersection Observers for scroll animations, count-up animations, form synchronization, and modals.

## 💻 Local Preview

Run any local web server in this directory:

```bash
# Python
python -m http.server 3000

# Node.js
npx serve .
```

Open `http://localhost:3000` in your browser.
